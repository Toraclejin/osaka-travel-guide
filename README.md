# 오사카 여행 가이드

**2026-08-24(월) ~ 08-26(수) · 2박 3일 · 남자 4명 · 페리 입출항.**
링크 하나만 열면 되는 DAY 기반 읽기 전용 가이드 — 날짜별 흐름 · 지도 동선 · 장소 · 일본어.

- **DAY별 시간표** — 시각은 참고용, 못 박은 건 시설 마감과 배 시간뿐
- **구역 지도** — 번호 핀 + 도보 순서 동선 점선 + 숙소 핀 & loop
- **이동 경로** — 현지 안내판과 같은 노선 기호(Ⓜ Ⓒ) + 구글맵 대중교통 길찾기
- **장소 37곳** — 관광지 25 · 맛집 8 · 카페 4. 탭하면 구글맵이 열림
- **탭 3개** — 여행 / 알아둘 것(응급·지진·매너·결제) / 일본어(75문장)
- 모바일 우선, **단일 HTML 파일**, 비번 없음

## 장소 추가·수정

`index.html` 안의 `GUIDE_DATA` 를 고칩니다. **별도 데이터 파일은 없습니다** — 이 파일 하나가 정본입니다 (R-D1).

```js
{"name_ko":"오사카성 천수각","name_en":"Osaka Castle","feature":"1583년 히데요시 축성. ¥1,200 · 입관 17:30 마감",
 "recommended":true,"essential":true,"lat":34.6873,"lng":135.5259,
 "maps_url":"https://www.google.com/maps/search/?api=1&query=Osaka%20Castle"}
```

한 줄에 한 장소를 씁니다. **배열 순서가 곧 지도 동선**이라 순서를 바꾸면 번호·범례·동선이 함께 바뀝니다.

⚠ 좌표를 넣은 뒤에는 반드시 **land-check**(R-D3)와 **구글맵 쿼리 역검증**(R-D12)을 거치십시오. 실제로 검색어 하나가 **중국 쿤밍의 훠궈집**을 가리킨 적이 있습니다.
