# 오사카 여행 가이드

같이 가는 사람 전원이 링크 하나만 열면 되는 오사카·교토 가이드 — 구역별 **관광지·맛집·카페** + **교토 당일 원정**.

- 구역별 인터랙티브 지도(번호 핀 + **도보 순서 동선 점선**) + 각 장소 구글맵 링크
- 카테고리 / ★추천 / 🇰🇷한국인 필수 필터
- 교토 가는 법 4가지 + 구글맵 길찾기 버튼
- 모바일 우선, 단일 HTML 파일

## 사용법

`index.html` 을 브라우저로 열면 됩니다. (지도 표시에는 인터넷 필요, 나머지는 오프라인에서도 동작)

접속 비밀번호가 걸려 있습니다. 힌트는 화면에 나옵니다.

**`overview.html`** — 일행과 같이 보는 **계획표**입니다. DAY별 흐름·장소·구글맵 링크가 한 장에 있고, 비밀번호 없이 열립니다.

**`hotel.html`** — 숙소 안내 한 장 (비용·온천·객실 구성). 일행에게 보여주는 용도이고 비밀번호 없이 열립니다.
⚠ 이건 **손으로 유지**합니다 — 예약이 바뀌면 같이 고쳐야 합니다.

⚠ **자동 생성물이라 직접 고치지 마십시오.** 장소 데이터를 바꾼 뒤 아래를 돌리면 됩니다.

```bash
node tools/build-overview.js
```

## 장소 추가·수정

`index.html` 안의 `GUIDE_DATA` (시내 구역) 또는 `EXCURSIONS` (원정) 객체를 고칩니다.
별도의 데이터 파일은 **없습니다** — 이 파일 하나가 정본입니다.

```js
{"name_ko":"오사카성","name_en":"Osaka Castle","feature":"천수각 + 해자 + 공원. 최소 2시간",
 "recommended":true,"essential":true,"lat":34.6873,"lng":135.5259,
 "maps_url":"https://www.google.com/maps/search/?api=1&query=Osaka%20Castle"}
```

한 줄에 한 장소를 씁니다. 좌표를 넣은 뒤에는 **반드시 지도에서 핀 위치를 눈으로 확인**하세요.

## 로컬 서버

```bash
npx --yes serve -l 8767 .
```

## ⚠ 현재 상태 (v0.5)

- 구역 5개 + 교토 원정 1개 · 관광지 24곳 — **좌표 검증 완료**
- 구역 접근 정보 — 역 기준으로 작성 (숙소 미정이어도 동작)
- **동선** — 구역별 번호 순서 점선. 직선이라 실제 도로 경로는 아님 (CSP상 경로 API 호출 불가)
- **맛집·카페 — 0곳.** 가장 큰 공백
- **서브컬쳐 · 역사·문화 테마 — 스키마 설계 완료, 데이터 0곳** (동행 요청 반영)
- 숙소 — 미정 (매스트헤드 호텔 칩이 생략되고, 원정 길찾기는 오사카역 출발로 대체)

자세한 내용은 [`CLAUDE.md`](CLAUDE.md) § 13.
